# Supabase Todo App

A Todo List application built using JavaScript and Supabase. This project focuses on managing tasks with a backend database for storing and retrieving todo items.

## 🚀 Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Store tasks in a Supabase database
- Fetch and display tasks dynamically
- Interactive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase

## 📚 Concepts Practiced

- DOM Manipulation
- Event Handling
- CRUD Operations
- Database Integration
- API Requests
- Asynchronous JavaScript
- `async/await`
- Promises
- JSON Data
- Error Handling

## 🗄️ Supabase Integration

Supabase is used as the backend database to store and manage todo items. The application communicates with Supabase to create, retrieve, update, and delete tasks.

## 🎯 Purpose

The purpose of this project is to practice JavaScript, learn backend database integration, and understand how to build a dynamic application using Supabase.
